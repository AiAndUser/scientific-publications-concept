# Экспертная карта

## Что это

Виртуальная карта, привязанная к профилю эксперта.
Аналог «Пушкинской карты», но для научной экспертизы.

## Параметры

| Параметр | Значение |
|---|---|
| Годовой баланс | 5 000 ₽ |
| Стоимость лайка | 100 ₽ |
| Максимум лайков в год | 50 |
| Пополнение | 1 января, автоматически |
| Сгорание остатка | 31 декабря |
| Передача | Невозможна |
| Пополнение извне | Не предусмотрено |

## Что видит эксперт

- Баланс: потрачено, осталось, до конца года.
- История лайков: когда, какая статья, сколько.
- Напоминание о сгорании (например, в декабре).

## Что видит система

- Все транзакции прозрачны.
- Аномалии фиксируются.
- Нарушения → блокировка карты.
