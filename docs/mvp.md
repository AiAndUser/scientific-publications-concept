# MVP — что можно сделать уже сейчас

## Без господдержки, без блокчейна

### Этап 1. Сайт-визитка

- Описание идеи.
- Форма обратной связи.
- Приглашение к обсуждению.

### Этап 2. Платформа с бесплатными лайками

- Регистрация (email).
- Ручная верификация диплома.
- **Проверка статуса самозанятого (для будущих выплат).**
- Публикация статей (PDF).
- Ручная модерация.
- Бесплатные лайки (для рейтинга).

### Этап 3. Пилот с платными лайками

- Малый грант или краудфандинг.
- Ограниченный пул экспертов.
- **Выплаты только самозанятым авторам.**
- Автоматический налог (6%).

### Этап 4. Масштаб

- Господдержка.
- «Экспертные карты».
- Автоматическая верификация.
- Рейтинги и топы.

## Технологии (без обязательств)

- Backend: Python (Django/FastAPI) или Node.js.
- База данных: PostgreSQL.
- Frontend: React или Vue.
- Хостинг: любой доступный.
- Блокчейн: не обязателен.
