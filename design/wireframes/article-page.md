# Wireframe — Страница статьи

Это не макет. Не финальный дизайн.
Просто текстовое описание: как **могла бы** выглядеть
страница статьи.

Всё мягко. Всё можно менять.

---

## Общая структура

┌─────────────────────────────────────────────┐
│ [Логотип] [Статьи] [Поиск] [Профиль] │
├─────────────────────────────────────────────┤
│ │
│ Заголовок статьи │
│ Автор • Дата публикации │
│ │
│ Аннотация: │
│ Текст аннотации (2–4 строки). │
│ │
│ Ключевые слова: [наука] [метод] [анализ] │
│ │
│ [Скачать PDF] │
│ │
│ ┌───────────────────────────────────────┐ │
│ │ ♡ 27 лайков │ │
│ │ ♡ Экспертные лайки: 27 × 100 ₽ │ │
│ └───────────────────────────────────────┘ │
│ │
│ Комментарии (если включено): │
│ • Комментарий 1 │
│ • Комментарий 2 │
│ │
│ Похожие статьи: │
│ • Статья 1 │
│ • Статья 2 │
│ │
└─────────────────────────────────────────────┘


---

## Блоки

### Шапка
- Логотип.
- Навигация.
- Поиск.

### Заголовок
- Крупно, чётко.

### Автор и дата
- Мягко, второстепенно.

### Аннотация
- 2–4 строки.

### Ключевые слова
- Теги.

### Кнопка «Скачать PDF»
- Основное действие.

### Лайки
- Обычные.
- Экспертные.
- Прозрачно.

### Комментарии
- Если включено.
- Модерация.

### Похожие статьи
- 2–3 штуки.

---

## Что важно помнить

- **Читаемость.** Много воздуха.
- **Прозрачность.** Лайки видны.
- **Мягкость.** Без давления.
